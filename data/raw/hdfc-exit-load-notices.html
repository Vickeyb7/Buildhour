HDFC Exit Load & Addenda Disclosures

Source URL: https://www.hdfcfund.com/statutory-disclosure/notice-addenda

Type: charges

exit_load_rules

HDFC Mutual Fund Exit Load Structure: For equity growth schemes, an exit load of 1.00% is typically levied if units are redeemed within 365 days; after 1 year, exit load is Nil. ELSS schemes have Nil exit load but a statutory 3-year lock-in.

exit_load_exemption

HDFC Mutual Fund Exit Load Applicability: Exit load is calculated using the First-In-First-Out (FIFO) method on units redeemed. Bonus units and dividend reinvestment units are exempt from exit load.
